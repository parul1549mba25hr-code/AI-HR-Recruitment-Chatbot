# AI HR Recruitment Chatbot 🤖

## Overview
This project is an AI-powered HR chatbot developed using Dialogflow. It helps automate candidate queries related to recruitment.

## Features
- Provides job openings information
- Explains application process
- Shares interview details
- Gives company information

## Tools Used
- Dialogflow (Google AI)
- Natural Language Processing (NLP)

## How It Works
The chatbot uses intents and training phrases to understand user queries and respond accordingly.
